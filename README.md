# Premium-Calm

Copy of the Premium site with a calm, animated background that you can switch from the settings menu (Background row), or with `?bg=aurora|silk|dust|beams|off` in the address.

- Aurora: three huge soft glows drifting very slowly (CSS only)
- Silk: thin flowing lines (canvas)
- Dust: a few slowly floating specks (canvas)
- Beams: faint light shafts sweeping sideways (CSS only)

Colours follow the active palette. Animation stops on Quality: Light and with reduced-motion.
